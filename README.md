Рассчет метрик в marts:
1. Средний чек: 
   Рассчитывается в fact_sales_daily.avg_transaction_amount для группы date_key, store_key и product_key как среднее число тех чеков, которые содержат данный товар в данный день в данном магазине. Реализовано через check_totals -> grain (чек * товар) -> avg(check_total).
2. Сопоставимые продажи:
   Это продажи, которые посчитаны только по сопоставимой базе - магазинам и/или товарам, которые работали в обоих сравниваемых периодах. Исключаются новые, закрытые и реконструированные точки, чтобы рост отображал органическую динамику, а не раширение сети. Считается как (сумма продаж по сопоставим магазинам за текущий период)/(сумма продаж по тем же магазинам за базовый период - 1) * 100%
